GitHub bot slash-command autocomplete - Installation
=====================================================

This folder holds the packaged Chrome extension (gh-slash-autocomplete-<version>.crx)
and the scripts that install, update and uninstall it on Windows, macOS and Linux.
On Windows they also work on managed Chrome browsers.

  gh-slash-autocomplete-<version>.crx    The extension.
  install-gh-slash-extension.bat         Installs or updates the extension (Windows).
  uninstall-gh-slash-extension.bat       Removes the extension (Windows).
  install-gh-slash-extension.command     Double-click to install or update (macOS).
  uninstall-gh-slash-extension.command   Double-click to remove the extension (macOS).
  scripts\                               The scripts the files above run, and the helpers
                                         they share: PowerShell scripts for Windows, shell
                                         scripts for macOS and Linux.
  src\                                   The extension's source files, for the manual install
                                         (see "MANUAL INSTALL").

The sections below are for Windows. macOS and Linux are covered in the last
section, "MACOS AND LINUX".


BEFORE YOU START
----------------

Unzip the release into a PERMANENT folder, for example
C:\code\gh-slash-autocomplete.

Chrome loads the .crx straight from that folder, so do not move or delete the
folder after installing. If you do, the extension stops working.


INSTALL
-------

1. Double-click install-gh-slash-extension.bat.

2. Click Yes when Windows asks for Administrator permission.

3. If Chrome is open, the installer says it must be closed and asks
   "Close Chrome now? (y/n)". Press y or n (no Enter needed).

   - y: the installer closes Chrome the normal way, as if you clicked the X on
     each window, and reopens it with your tabs when it finishes. If Chrome
     doesn't close within 5 seconds, it asks whether to try again.
   - n: the installer stops without changing anything. Close Chrome yourself
     (all windows, and any Chrome icon in the system tray), then run the
     installer again.

4. When the installer finishes, press Enter to close its window.

5. Turn the extension on (one time only). Chrome keeps extensions that are not
   from the Chrome Web Store switched off the first time:

     a. Open Google Chrome. (The installer already reopened it if it closed it
        for you.)
     b. Go to chrome://extensions
     c. Find "GitHub bot slash-command autocomplete" and switch it ON.

   The extension icon is pinned to your toolbar automatically, and the
   extension stays on after Chrome restarts.


UPDATE
------

1. Unzip the newer release into the SAME folder, replacing the files when asked.
2. Run install-gh-slash-extension.bat again. It finds the newest .crx, reads its
   version number and updates Chrome.

If an older .crx is still in the folder, the installer uses the most recently
modified one, which is the one from the newer release. You can delete the old
one.


MANUAL INSTALL (WITHOUT THE INSTALLER)
--------------------------------------

Use this on any operating system if you can't run the installer scripts, or
just want to try the extension. Chrome loads the extension straight from a
folder of source files, so this uses the "src" folder in this release, not the
.crx. (Dragging the .crx onto chrome://extensions doesn't work: Chrome blocks
extensions that don't come from the Chrome Web Store.)

1. Unzip the release into a PERMANENT folder, if you haven't already. The
   folder you need is the one named "src", which contains manifest.json.

   Chrome loads the extension from this folder, so do not move or delete it
   after installing. If you do, the extension stops working.

2. In Chrome, go to chrome://extensions

3. Turn on "Developer mode" (the switch in the top-right corner).

4. Click "Load unpacked", pick the "src" folder (the one that contains
   manifest.json), and click Select Folder.

5. "GitHub bot slash-command autocomplete" now appears in the list, already
   switched on. To keep its icon in the toolbar, click the puzzle-piece
   button in Chrome's toolbar and then the pin next to the extension.

Notes:

  - To update, unzip the newer release over the same folder, go to
    chrome://extensions and click the reload icon on the extension's card.
  - To remove it, click Remove on the extension's card.
  - Don't use this together with the installer. Chrome would show the
    extension twice. If you installed it with the installer, run the
    uninstaller first.
  - Chrome may show a "Disable developer mode extensions" prompt when it
    starts. Dismiss it (or choose Keep) to leave the extension on.


UNINSTALL
---------

1. Double-click uninstall-gh-slash-extension.bat.

2. Click Yes when Windows asks for Administrator permission.

3. The uninstall doesn't need Chrome closed, but Chrome only notices the
   removal when it restarts. If Chrome is open, the uninstaller offers to
   restart it for you: "Close Chrome now? (y/n)".

   - y: Chrome is closed the normal way and reopened with your tabs when the
     uninstall finishes. If it doesn't close within 5 seconds, you are asked
     whether to try again.
   - n: the uninstall carries on and leaves Chrome open. Restart Chrome
     yourself afterwards (close all of its windows, then reopen it).

4. Go to chrome://extensions and click Remove on the extension if it is still
   listed.


TROUBLESHOOTING
---------------

The extension doesn't appear after installing
  - Make sure Chrome was fully closed and reopened. Chrome only reads the new
    registration when it starts.
  - Check that the .crx is in the same folder as install-gh-slash-extension.bat.

The installer stopped because Chrome is still running
  - Close Chrome completely (all windows, and any Chrome icon in the system
    tray), then run the installer again. Nothing is changed when it stops.

Windows blocks the script (execution policy)
  - Open PowerShell in this folder and run:

      powershell -ExecutionPolicy Bypass -File .\scripts\install-gh-slash-extension.ps1


MACOS AND LINUX
---------------

These steps work for Google Chrome on macOS and Linux, and for Chromium on
Linux. The installer sets up every one of those browsers it finds. Chromium
installed as a snap or Flatpak is not supported, and neither are other
Chrome-based browsers.

Unzip the release into a PERMANENT folder, for example ~/gh-slash-autocomplete.
Chrome loads the .crx straight from that folder, so do not move or delete it
after installing.

Install or update:

1. On a Mac, double-click install-gh-slash-extension.command. It opens
   Terminal and runs the installer. (Linux has no double-click launcher; use
   the terminal command further down.) The first time, macOS may say it can't
   check the file for malicious software; click Done, open System Settings ->
   Privacy & Security, scroll down and click "Open Anyway" next to the
   file's name, then double-click it again.

   Or, on a Mac or Linux, open a terminal in the folder and run:

     ./scripts/install-gh-slash-extension.sh

   If your system says "permission denied", run it as:
   bash scripts/install-gh-slash-extension.sh

   Run it as yourself. Do not use sudo; the script asks for sudo itself only
   when it needs it.

2. If the browser is open, the installer asks "Close it now? (y/n)". Press y or n
   (no Enter needed). y closes Chrome the normal way and reopens it with your
   tabs when it finishes. n stops without changing anything.

3. Turn the extension on (one time only): go to chrome://extensions and switch
   "GitHub bot slash-command autocomplete" ON.

4. Pin the icon.

   - Linux: the installer pins it for you. It asks for your sudo password to
     write a browser policy file: /etc/opt/chrome/policies/managed/
     gh-slash-autocomplete.json for Chrome, and /etc/chromium/policies/managed/
     gh-slash-autocomplete.json for Chromium. If you decline, the extension
     still installs; pin the icon yourself with the puzzle-piece button in the
     browser's toolbar.
   - macOS: pin the icon yourself with the puzzle-piece button.

To update, unzip the newer release over the same folder and run the installer
again. It uses the newest .crx it finds.

Uninstall:

   Double-click uninstall-gh-slash-extension.command (Mac), or run:

     ./scripts/uninstall-gh-slash-extension.sh

If the browser is open, it offers to restart it, as on Windows. On Linux it
also removes the policy files (asking for your sudo password). Then go to
chrome://extensions and click Remove if the extension is still listed.

If macOS says it is blocking Chrome's files ("Operation not permitted"):
Some Macs stop terminal apps from changing Chrome's files. The installer
checks this before it closes Chrome or changes anything, and if it is blocked
it installs for every user of the Mac instead:

  - It asks for your administrator password.
  - It keeps a copy of the .crx in /Library/Application Support/
    gh-slash-autocomplete, so the folder you unzipped no longer has to stay
    in place. Updating means running the installer from the newer release.
  - It skips the cleanup of a previous removal of the extension, which needs
    the blocked files. If you removed the extension from Chrome before and it
    doesn't come back, turn it on at chrome://extensions or allow the terminal
    below and install again.

The uninstaller removes this system-wide copy too, also asking for the
administrator password.

To install just for yourself instead:

  1. Open System Settings -> Privacy & Security -> Full Disk Access.
  2. Switch on the terminal app you run the script in (Terminal, iTerm, ...).
     If it isn't listed, click + and add it.
  3. Quit that terminal app completely (Cmd+Q), open it again, and run the
     script again.

If the installer says you need administrator rights and you don't have them,
your Mac may be managed by your organization; ask your IT team. The manual
install (above) doesn't need either permission.

The installer needs perl (already on macOS and almost every Linux). Add
--no-pause to either script to run it without any prompts; Chrome is then left
open and you restart it yourself.
