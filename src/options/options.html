Slash commands

Commands suggested when you type / in a GitHub comment box. The extension adds commands found in comments on the pages you visit. Edit, disable or remove any of them, or add your own. Under Arguments, list what a command accepts after it, such as review for /q review.

How it works

  • Type / in a GitHub comment box to see suggestions. After a command and a space, it suggests that command's arguments.
  • Commands are found automatically in comments on pages you visit. Use Add command to add your own.
  • Untick a command's checkbox to stop suggesting it. Clicking I in the popup does the same.
  • Under Arguments, list what a command accepts. Untick the box beside it to stop new arguments being added automatically.
  • Under Only for, limit a command to users, organizations or repositories, such as acme, acme/site. Put ! in front to exclude one.
  • Export and Import share your commands as a JSON file.
