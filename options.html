Slash commands

Commands suggested when you type / in a GitHub comment box. The extension adds commands it finds in comments on the pages you visit. Edit, disable or remove any of them, or add your own. Under Arguments, list what a command accepts after it, such as review for /q review. After you type the command and a space, the popup suggests them. Arguments the extension finds on pages are a single word; ones you add yourself can be several, such as review this.
